## 📌 Descripción General

**El Gran Coliseo** es una aplicación web open-source orientada a la comunidad de esports y Dota 2. Proporciona una interfaz ágil, reactiva y visualmente inmersiva para visualizar emparejamientos, brackets de eliminación, estadísticas de héroes y gestión de equipos en torneos competitivos.

Construida aprovechando las últimas capacidades de **Next.js 14 App Router** y el nuevo motor ultra veloz de **Tailwind CSS v4**.

---

## ✨ Características Principales

* 🏆 **Gestión y Visualización de Torneos:** Interfaz fluida para consultar brackets de eliminación directa y tablas de posiciones.
* ⚡ **Arquitectura Next.js 14 App Router:** Renderizado híbrido (SSR/SSG) con Server Components para máxima velocidad de respuesta y SEO óptimo.
* 🎨 **Diseño Oscuro Inmersivo (Dark-First):** Estética gaming de alta fidelidad con micro-interacciones fluidas y componentes responsivos en Tailwind CSS v4.
* 📱 **Experiencia Mobile-First:** Diseñada para adaptarse a cualquier resolución de pantalla, desde dispositivos móviles hasta pantallas ultrawide.
* 🚀 **Despliegue Continuo:** Conectado directamente a Netlify con pipelines de compilación automática.

## 🚀 Instalación y Puesta en Marcha

### Prerrequisitos
* Node.js v18.17 o superior
* pnpm instalado (`npm install -g pnpm`)

### 1. Clonar el repositorio
```bash
git clone https://github.com/Alecwce/el-gran-coliseo.git
cd el-gran-coliseo
```

### 2. Instalar dependencias
```bash
pnpm install
```

### 3. Iniciar el servidor local
```bash
pnpm dev
```
Abre tu navegador en [http://localhost:3000](http://localhost:3000) para ver la aplicación.

### 4. Compilar para producción
```bash
pnpm build
```
